# ForeverCDs

A cooldown tracker for **WoW: Forever**. It starts with Innervate, and you can add any spell.

- Tracks **every group member who can cast a tracked spell**: no healer-only filter, so Feral and Balance druids show up.
- Party and raid (up to 40). Nobody else needs the addon.
- Honest about what it knows: a cooldown it hasn't seen start shows as *assumed ready* (`?`), never as a guessed "Ready".
- A movable window, or in a party, small icons on each member's unit frame. Works with Blizzard frames, ForeverUnitFrames, ElvUI, Shadowed UF, Cell, Grid2 and most other unit-frame addons.
- Presets (off by default): Rebirth, Tranquility, Mana Tide Totem, Blessing of Protection, Lay on Hands, Divine Intervention, Fear Ward, Power Infusion, Soulstone Resurrection.
- Timers survive `/reload` and relog. Optional ready and cast alerts.
- Built for Forever's addon rules: no combat log, every value checked for secrets.

Type `/fcds` for options, `/fcds test` to preview, `/fcds help` for all commands.
